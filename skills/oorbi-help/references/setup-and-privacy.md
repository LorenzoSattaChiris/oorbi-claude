# Links

When Oorbi is connected, `get_oorbi_context` returns the current links for this account (Moves, Training, setup check). Prefer those. Otherwise use:

| What | Link |
|---|---|
| Setup check for Oorbi in Chrome | https://oor.bi/troubleshoot |
| Update Oorbi in Chrome | https://oor.bi/update |
| Check an AI's training setting | https://oor.bi/data-sharing |
| Moves in Oorbital | https://app.oorbital.ai/moves |
| Training | https://app.oorbital.ai/training |
| Privacy policy | https://oorbital.ai/privacy |
| Terms | https://oorbital.ai/terms |

# What each check can see

| Check | Runs in | Sees |
|---|---|---|
| Oorbi here (this AI) | Oorbital's servers, through this AI | The person's Oorbital account and libraries, and only what Oorbi's tools are given |
| Setup check | The person's browser | Whether Oorbi in Chrome is installed, up to date, signed in and able to read the AI page |
| Oorbi in Chrome protection | The person's browser | The prompt and files before they are sent on supported AI websites |

A remote connection cannot read the person's browser, extensions, files or device. Only the setup check in their own browser can.
